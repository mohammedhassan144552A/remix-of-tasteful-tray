# Remix of Tasteful Tray

🚀 البرومبت الكامل لإنشاء منصة مطعم أرز ووجبات احترافية باستخدام Lovable



أريد منك بناء منصة مطعم احترافية وكاملة لبيع الأرز والوجبات والمأكولات باستخدام Lovable، وتكون جاهزة للعمل فعليًا وليست مجرد واجهة تجريبية.



المشروع يجب أن يكون باللغة العربية بشكل أساسي، ويدعم RTL بالكامل، ويكون سريعًا ومتجاوبًا مع الجوال والتابلت والكمبيوتر.

2. اللغة والاتجاه



- اللغة الأساسية: العربية.

- اتجاه الموقع: RTL.

- دعم اللغة الإنجليزية يمكن إضافته مستقبلًا.

- جميع النصوص قابلة للتعديل من لوحة التحكم.

- العملة: الريال السعودي SAR / ر.س.

- تنسيق أرقام الجوال مناسب للسعودية.

- التحقق من رقم الجوال السعودي.

- عدم استخدام نصوص Lorem Ipsum.

- عدم ترك أي نصوص تجريبية في الواجهة النهائية.

- الوظائف.

التصميم الجديد يجب أن يكون:



- حديثًا.

- فاخرًا.

- واضحًا.

- مناسبًا للمطاعم.
